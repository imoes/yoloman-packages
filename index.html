YOLO-MANager package repository

Version 0.57.73. Docker Compose remains the primary deployment; these packages are for hosts where a container runtime is not wanted. yoloman-agent is the node agent, yoloman-bossman the fleet controller.

Debian / Ubuntu

curl -fsSL https://imoes.github.io/yoloman-packages/yoloman-archive-keyring.asc | sudo gpg --dearmor -o /usr/share/keyrings/yoloman-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/yoloman-archive-keyring.gpg] https://imoes.github.io/yoloman-packages/deb stable main" | sudo tee /etc/apt/sources.list.d/yoloman.list
sudo apt update
sudo apt install yoloman-agent      # a managed node
sudo apt install yoloman-bossman    # the controller

RHEL / AlmaLinux / Rocky / Fedora

sudo tee /etc/yum.repos.d/yoloman.repo <<'REPO'
[yoloman]
name=YOLO-MANager
baseurl=https://imoes.github.io/yoloman-packages/rpm
enabled=1
gpgcheck=1
gpgkey=https://imoes.github.io/yoloman-packages/rpm/repodata/repomd.xml.key
REPO
sudo dnf install yoloman-agent
sudo dnf install yoloman-bossman

Bossman needs a database

PostgreSQL with the timescaledb and pgvector extensions. The package does not install it, and the postinst prints the four steps; the full walk-through is the Quick start in the README.
